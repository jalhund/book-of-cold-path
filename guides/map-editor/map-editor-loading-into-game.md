# Загрузка в игру

После того, как вы создали карту, используйте экспортированный пакет **`.map`**, а не рабочую папку `exported_map/`.

Windows: положите пакет рядом с исполняемым файлом Cold Path или в подпапку `maps/`. Карты обнаруживаются при открытии новой игры. Кнопка **Импорт карты / Import map** в Dev menu проверяет пакеты и показывает ошибки.

Android: откройте **Настройки - Dev menu - Импорт карты / Import map** и выберите `.map` в системном диалоге. Вручную помещать карту в `Android/data` не требуется.

Путь `D:/` и префикс `ColdPath` в именах файлов больше не нужны. Поддерживается несколько карт; в списке новой игры они отображаются по именам файлов. Пакет с уже установленным ID не заменяется автоматически.

Итак, вы создали карту, положили по нужному пути. Далее зайдите в игру. Новая игра - Карта - выберите свою карту. У вас прогрузится карта, созданная вами. Сценарий, который там есть, - автоматически сгенерированный. В нем есть только одна страна. Этот сценарий нужен лишь для того, чтобы на его основе сделать свой. Поэтому далее нужно открыть Редактор сценариев, выбрать пользовательскую карту \(Custom map\), и создать свой сценарий для этой карты. Далее его нужно экспортировать \(Export to JSON\), потом подгрузить (на Windows — из папки игры, на Android — кнопкой Импорт сценария в Dev menu). Готово! Вы можете играть на своем сценарии на своей карте!

Как играть по сети? Пользовательские карты поддерживаются: начните одиночную игру на своей карте и выберите Открыть сервер. Пакет автоматически передаётся подключающимся игрокам и сохраняется у них в кэш. Для отдельного сервера см. [настройку сервера](../../server/customization.md).

Старые папки `exported_map/` сначала преобразуйте текущим редактором кнопкой **Convert legacy map / Convert to .map**.
