# Purchase issues solution

### Game did not sync purchases

1. Close game\(you can use Exit button in the game\)
2. Turn on internet. Make sure there are no connection problems
3. Open game

Purchases should be made available. I advise you to check availability not in the Premium menu, but directly trying to access the game features \(for example, select the purchased Technocracy\)

### Wrong google account

In the Google Play version, use the Google account that made the purchase and the same game account. In the YooKassa payment build, purchases are restored through the game account; the Google account is not used for them.

### If none of the above helps

If none of the above helped, contact the developer with the product, game version, payment provider and order number or receipt. Save your recovery code and needed games before clearing app data: clearing removes local data and does not restore a purchase by itself.

### Recovering the game account

After reinstalling or on another device, open **Settings - Profile - Restore account** and enter the saved code. Wait for purchases to synchronize over the internet. A new recovery code invalidates the previous one.

Scenario Editor, ordinary multiplayer and commands no longer require the former Premium purchases. Technocracy, Military Junta, Espionage and the Africa pack are separate purchases.
